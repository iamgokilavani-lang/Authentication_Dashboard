# Wanderlust Pro — Booking Dashboard

A Vite-powered travel and booking management dashboard built with HTML, CSS and JavaScript.

## Run locally

```bash
npm install
npm run dev
```

The development server uses port 5174 by default so it can run alongside the Authentication Dashboard on port 5173.

## Production build

```bash
npm run build
```

The production files are generated in:

```text
dist/
```

## Netlify

For this project, use:

- Base directory: `projects/booking-dashboard`
- Build command: `npm run build`
- Publish directory: `dist`
